One two-part micro-confession — a To: line and the unsent line itself, exactly as it was typed — written to `/output/entry.txt` by a stdlib-only Python program.

Entry for the make.fun bounty [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

## Run it

```sh
python3 main.py
```

It writes the confession to `/output/entry.txt` (152 characters, two lines) and prints it.
